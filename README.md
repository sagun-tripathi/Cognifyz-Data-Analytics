# Cognifyz Data Analysis & Visualization Internship

This repository contains my work for the Cognifyz Technologies Data
Analysis / Data Visualization internship tasks.\
The project is based on the provided investment preference dataset and
focuses on analysing investor behaviour, identifying useful patterns,
and presenting the results through Excel analysis and a dashboard.

## Project Overview

The dataset contains information about investors such as:

-   Gender and age
-   Preferred investment avenues
-   Savings objectives
-   Investment duration
-   Expected returns
-   Sources of investment information
-   Reasons for selecting different investment options
-   Investment monitoring and expectations

I worked on the dataset in three levels, starting with basic analysis
and gradually moving towards correlation analysis and dashboard
creation.

------------------------------------------------------------------------

## Levels Completed

### Level 1 -- Basic Analysis

**Task 1: Gender Distribution**

I analysed the gender distribution of the respondents and calculated the
count and percentage for each category.

**Task 2: Investment Preferences**

I analysed the investment avenues selected by respondents and compared
the major investment options. I also looked at the reasons associated
with different investment choices.

Main investment avenues covered:

-   Mutual Funds
-   Equity
-   Fixed Deposits
-   Public Provident Fund (PPF)

------------------------------------------------------------------------

### Level 2 -- Intermediate Analysis

**Task 3: Savings Objective and Information Source**

This task focuses on understanding why people save/invest and where they
get investment-related information.

The analysis includes:

-   Savings objectives
-   Sources of investment information
-   Comparison of respondent counts across categories

**Task 4: Investment Duration and Expected Return**

I analysed how long respondents generally plan to keep their investments
and what level of return they expect.

The analysis covers:

-   Less than 1 year
-   1--3 years
-   3--5 years
-   More than 5 years

Expected return categories:

-   10%--20%
-   20%--30%
-   30%--40%

------------------------------------------------------------------------

### Level 3 -- Advanced Analysis & Dashboard

**Task 5: Correlation Analysis**

For this task, categorical values for investment duration and expected
return were converted into simple numeric values so that their
relationship could be visualised.

The analysis compares:

-   Age
-   Investment duration
-   Expected return

The correlation matrix was used to understand whether there is any
noticeable relationship between these variables.

**Task 6: Data Visualization Dashboard**

I created an Excel dashboard to present the main findings in a simple
and easy-to-read format.

The dashboard includes:

-   Total respondents
-   Average age
-   Top investment avenue
-   Top savings objective
-   Top information source
-   Gender distribution
-   Investment avenue distribution
-   Information source distribution
-   Investment duration distribution
-   Savings objective distribution
-   Expected return distribution
-   Gender and duration filters

------------------------------------------------------------------------

## Key Findings

Some of the main observations from the analysis are:

-   The dataset contains 40 usable respondents.
-   Male respondents are higher in number than female respondents.
-   Mutual Funds are the most selected investment avenue in the dataset.
-   Retirement Planning is the leading savings objective in the Level 2
    analysis.
-   Financial Consultants are the most common information source.
-   Most respondents prefer an investment duration of 3--5 years.
-   The 20%--30% expected return range is the most common expectation.
-   Capital Appreciation is a major savings/investment objective in the
    dashboard analysis.

These observations were used while designing the final dashboard.

## Approach

I followed a step-by-step approach for the project:

1.  Reviewed the supplied dataset.
2.  Identified the required columns for each task.
3.  Calculated category-wise counts and percentages where required.
4.  Compared investment preferences and investor objectives.
5.  Analysed investment duration and expected return.
6.  Created simple numeric mappings for the correlation analysis.
7.  Built charts and summary sections in Excel.
8.  Combined the important findings into a final dashboard.
9.  Added filters and key metrics to make the dashboard easier to
    explore.
